## HTTP 400 INVALID_ARGUMENT investigation (live smoke)

### A. Confirmed root cause

Zod `toJSONSchema` được gửi qua field SDK **`responseSchema`** (OpenAPI subset), trong khi payload là JSON Schema đầy đủ (Draft 2020-12) với keyword **`$schema`**, **`const`**, **`pattern`**, **`oneOf`**, **`prefixItems`**. Gemini structured output yêu cầu **`responseJsonSchema`** với subset keyword; schema OpenAPI/`responseSchema` và các keyword trên gây **`HTTP 400 INVALID_ARGUMENT`** trước khi model trả body.

`thinkingConfig.thinkingLevel` và model `gemini-3.6-flash` **không** là nguyên nhân đã xác nhận (mapping SDK đúng enum `ThinkingLevel.LOW`).

### B. Evidence

| Metric | Raw Zod schema | Sau `sanitizeJsonSchemaForGemini` |
|---|---|---|
| Serialized bytes | 7734 | 7377 |
| Max nesting depth | 17 | 17 |
| Property nodes | 429 | ~429 |
| Union branches | 10 (`oneOf`) | 10 (`anyOf`) |

Keywords bị loại khỏi generation schema: **`$schema`**, **`pattern`**, **`const`** (→ **`enum`**), **`oneOf`** (→ **`anyOf`**). Contract Zod `scriptSchema` / `llmScriptSchema` **không đổi** — vẫn validate sau response.

SDK `@google/genai` (worker dependency): `GenerateContentConfig` có **`responseJsonSchema`** riêng; tài liệu ghi dùng field này khi JSON Schema không map qua `responseSchema`.

Dump: `data/pipeline/p1-07-zod-json-schema.json`, `data/pipeline/p1-07-gemini-generation-schema.json` (script `analyze-gemini-schema.ts`).

### B. Confirmed root cause

**Gemini API rejects the Zod-derived generation schema** (`z.toJSONSchema(llmScriptSchema)` wrapped in `variants`), specifically the combination of:

1. **`anyOf` discriminated scene union (5 branches)** with per-branch `required` differences and nested objects.

**Variant D failure** implicates **residual Zod-derived structure** (especially nested `additionalProperties`), not `anyOf` alone.
