## 1. Thiết kế

Người làm: Claude Opus 5.5, phiên tự hành ([13-AUTONOMOUS-AGENT-WORKFLOW.md](../docs/13-AUTONOMOUS-AGENT-WORKFLOW.md)).

- Stack theo [02-SYSTEM-ARCHITECTURE.md](../docs/02-SYSTEM-ARCHITECTURE.md): React 19.3, Vite 7.3, Tailwind CSS 4.3 (`@tailwindcss/vite`), TanStack Query 5. Zustand và React Three Fiber chưa cài (chưa cần trước P4-01).
- shadcn: `components.json` (new-york, neutral, CSS variables) + `button`, `input`, `label`, `card` theo đúng kiểu file CLI sinh (rule react-3d). Viết tay vì CLI tương tác và cần mạng; nội dung tương đương bản CLI, `Button` dùng `@radix-ui/react-slot`. Lần sau có thể chạy `pnpm dlx shadcn@latest add <component>` cho component mới.
- Từ điển `src/i18n/vi.ts`: mọi chuỗi hiển thị, gồm nhãn nút.
- Session: `GET /api/session` quyết định login hay shell; `POST /api/session/login`/`logout` qua TanStack Query mutation. Lỗi login hiển thị theo `error.code` (`unauthorized` → "Mật khẩu không đúng.", `validation_error`, lỗi mạng, lỗi khác), **không** hiện message gốc từ server.
- `apiRequest` (`src/lib/api.ts`): `fetch` cùng origin, `credentials: "same-origin"`, parse lỗi bằng `apiErrorBodySchema` của `@studio/contracts`.
- Dev server `127.0.0.1:5173`, proxy `/api` → `127.0.0.1:3001` (`changeOrigin: false`): cookie `studio_session` và header Origin loopback khớp hook P2-02. Không CORS.
- Shell ba vùng (06-3D-UI-DESIGN mục Bố cục): trái "Dự án", giữa vùng studio (placeholder, chưa canvas — P4-01), phải "Chi tiết". Header có "Đăng xuất". Nút "Tạo dự án" để `disabled` cho tới P2-06.
- Chưa có router; P2-06 thêm khi có trang project.
