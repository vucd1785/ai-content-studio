## 1. Root architecture and implementation summary

Fastify 5 app (`buildApp`) với `@fastify/type-provider-zod` và schema Zod 4 từ `@studio/contracts`. Một Director: `STUDIO_PASSWORD` so khớp qua SHA-256 hai đầu vào + `timingSafeEqual`. Session stateless: cookie `studio_session` = `base64url(JSON { v:1, exp })` + `.` + HMAC-SHA256(`STUDIO_SESSION_SECRET`, payload b64). TTL 604800 giây; `HttpOnly`, `SameSite=Lax`, `Path=/`, không `Secure`. Không Postgres/Redis session, không JWT, không thư viện auth.

Entry `src/main.ts`: `loadSessionEnv()` từ `@studio/config/session-env`, listen `127.0.0.1:3001`, `enableProbe: false`. Hook `onRequest`: (1) POST/PUT/PATCH/DELETE dưới `/api` — nếu có header `Origin` thì phải là `http(s)://127.0.0.1` hoặc `http(s)://localhost`; thiếu Origin vẫn cho phép (curl/inject); (2) route mở `login`, `logout`, `GET /api/session`; (3) mọi `/api` khác cần cookie hợp lệ, không thì 401. Route probe `GET /api/session-probe` chỉ khi `enableProbe: true` (test).

Login luôn ký cookie mới khi mật khẩu đúng; không tin cookie client. Logout `Max-Age=0`; cookie đã copy vẫn hợp lệ đến `exp`.

## 3. Session lifecycle

1. Boot: thiếu/rỗng `STUDIO_PASSWORD` hoặc `STUDIO_SESSION_SECRET` &lt; 32 ký tự → exit 1.
2. `POST /api/session/login` đúng → `Set-Cookie` + `{ authenticated: true }`.
3. Request sau → parse `Cookie`, verify HMAC + `v` + `exp`.
4. `GET /api/session` → boolean, không 401.
5. `POST /api/session/logout` → xóa cookie trình duyệt.
6. Hết `exp` → coi như chưa đăng nhập.

## 4. Security controls

| Kiểm soát | Triển khai |
|---|---|
| HMAC-SHA256 | `node:crypto` |
| Mật khẩu | SHA-256 + `timingSafeEqual`; không log/hash echo |
| Cookie | HttpOnly, SameSite=Lax, Max-Age/TTL 604800 |
| Malformed cookie | Trả invalid, không HTTP 500; MAC sai độ dài → false |
| Duplicate `studio_session` khác giá trị | Parse fail |
| Oversized value | &gt; 4096 từ chối |
| Zod lỗi | `validation_error`, `details: {}`, không echo input |
| Log redact | `cookie`, `password`, `set-cookie` |
| Origin | State-changing + Origin present → loopback only |
| Bind | `127.0.0.1` |

**Cổng trước P2-03:** Mọi route ghi dữ liệu mới (P2-03+) phải nằm sau cùng hook session và cùng quy tắc Origin. P2-05 cần proxy Vite cùng origin với API (`127.0.0.1` vs `localhost` là hai site).

## 7. Known stateless-session limitations (sau closeout)

- Logout không thu hồi cookie đã copy (I8: probe với bản copy vẫn 200 đến `exp`) — **giới hạn có chủ đích**; denylist/DB session ngoài MVP P2-02.
- Không rate limit brute force (chấp nhận trên loopback `127.0.0.1`).
- Không `Secure` (HTTP local; TLS cần ADR riêng).
- Đổi `STUDIO_SESSION_SECRET` cần restart; cookie cũ fail verify.
- **CSRF:** không token riêng; dựa `SameSite=Lax` (cross-site POST không gửi cookie). Client same-site vẫn cần discipline UI.
- **Origin:** POST/PUT/PATCH/DELETE `/api/*` từ chối `Origin` không loopback khi header có mặt; thiếu `Origin` vẫn cho phép (curl/inject). **Cổng bắt buộc P2-03+:** route ghi dữ liệu phải giữ hook session + Origin; P2-05 proxy Vite **cùng host** với API (`127.0.0.1` ≠ `localhost`).
