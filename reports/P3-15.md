# P3-15

- Objective: giao diện biết worker có đang chạy và chạy queue nào.
- Status: **pending — chờ Director verify**.

## Thiết kế

- Contract (`queue/job-payload.ts`): `WORKER_HEARTBEAT_PREFIX = "studio:worker:"`, TTL 30 s, làm mới 10 s, `workerHeartbeatSchema`, `workerStatusResponseSchema`.
- Worker (`queue/heartbeat.ts`, gắn trong `run-worker.ts`): ghi key `studio:worker:<host>-<pid>` kèm queue; dừng gọn thì xóa key, process chết thì key tự hết hạn.
- API (`routes/worker-status.ts`): `GET /api/worker-status` → `{ alive, queues, lastSeenAt }`, quét key theo prefix, bỏ giá trị sai schema; không trả id process hay URL Redis; Redis lỗi thì `alive: false`.
- API thêm dependency `redis` ^5.8.2 (cùng bản worker đang dùng, cài offline từ lockfile).
- Client Redis ở cả hai bên có listener `error` để mất Redis không làm sập process.
