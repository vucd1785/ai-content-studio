## Migration strategy

- **Source of truth:** TypeScript schema → `pnpm --filter @studio/db db:generate` → SQL in `packages/db/drizzle/`.
- **Apply:** `pnpm --filter @studio/db db:migrate` runs `drizzle-orm` migrator; tracks applied migrations in schema `drizzle.__drizzle_migrations`.
- **Idempotent re-run:** second+ invoke skips already-applied tags (Composer verified exit 0 with NOTICE on existing drizzle schema).

Default URL: `postgresql://studio:studio@localhost:5432/studio` (matches `.env.example` and `docker-compose.yml`).
