- Design decisions:
  - **API align:** body `{ audioArtifactId, transcript, engine? }`; response gồm `words`, `validation`, `gate`, `alignmentArtifactId` (cùng id audio); không trả path filesystem hay cache model.
  - **Engine mặc định:** `whisper` qua `ALIGNMENT_ENGINE` / `DEFAULT_ALIGNMENT_ENGINE` (ADR-011). CTC vẫn chọn explicit.
  - **Metrics:** thêm `timelineOrderRatio` (tỷ lệ từ không vi phạm thứ tự/chồng); `nonMonotonicWordRatio` = tỷ lệ từ vi phạm (đúng tên, trước đây lưu nghịch). `passesGate` yêu cầu `validation.ok` + phủ 90% + delta ±250 ms.
  - **Validation:** lệch số token là `error`; `ok` yêu cầu đủ token, interval dương, không overlap/lùi, trong duration.
  - **Whisper cache:** copy `base.pt` từ `C:\Users\PC\.cache\whisper\` sang `E:\AIModels\Whisper\` (SHA256 khớp); runtime dev đặt `WHISPER_CACHE_DIR=E:\AIModels\Whisper`. Bản gốc trên C giữ nguyên.
  - **Hợp đồng TS:** Zod trong `packages/contracts/src/media/tts.ts`; client mỏng `apps/worker/src/media-client.ts`.
