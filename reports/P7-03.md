# P7-03 — Duyệt tài sản ở Cổng 1

- **Objective:** Director duyệt phương án thì tài sản mới của phương án đó được duyệt luôn. Không có cổng thứ ba (ADR-017 mục 3).
- **Status:** **pending, chờ Director nghiệm thu.**
- **Người làm:** Claude Opus 5.5, ngày 2026-11-10.

## 1. Thay đổi

| File | Việc |
|---|---|
| `packages/db/src/workflow.ts` | `recordApproval`: cổng `script`, `approved` gọi `approveCandidateAssetsForVariant` trong cùng giao dịch; event `approval.recorded` thêm `approvedAssetIds` |
| `packages/db/src/motion-assets.ts` | `approveCandidateAssetsForVariant` (chỉ đổi `candidate` → `approved` của yêu cầu `fulfilled` thuộc đúng artifact và phương án) |

| `apps/api/src/routes/motion-assets.ts` (mới), `app.ts` | `GET /api/motion-assets`, `GET /api/workflow-runs/:runId/asset-requests`, `GET /api/motion-assets/:assetId/preview` (chỉ đọc) |

## 2. Kiểm tra

- Test tích hợp mới (3/3):
  - đọc yêu cầu kèm tài sản; ảnh thiếu file trả 404;
  - từ chối và yêu cầu sửa không đổi trạng thái tài sản;
  - duyệt phương án 1 chỉ đổi tài sản của phương án 1, event có `approvedAssetIds`.
- API 125/125, DB 14/14; typecheck sạch.

## 3. Giới hạn

- API không ghi file repo. `asset.json` được worker cập nhật khi job sau duyệt chạy, nên có độ trễ ngắn giữa DB và manifest.
- Không có route duyệt tài sản riêng. Muốn duyệt một tài sản ngoài Cổng 1 thì sửa `asset.json` tay hoặc dùng skill.
